# DEQM Summary MeasureReport (QRDA-III replacement)

Status date: 2026-08-07

This directory is the Phase 0/1 home for emitting **HL7 Da Vinci DEQM Summary
MeasureReports** — the FHIR aggregate replacement for **QRDA Category III**.

Workspace strategy:
`Vista-on-FHIR/docs/DEQM_SUMMARY_MEASUREREPORT_QRDA3_REPLACEMENT_STRATEGY.md`.

## Pin versions

| Artifact | Version |
|---|---|
| DEQM IG | STU5 **v5.0.0** (May 2025) |
| Profile | `http://hl7.org/fhir/us/davinci-deqm/StructureDefinition/summary-measurereport-deqm` |
| Scoring ext | `http://hl7.org/fhir/us/davinci-deqm/StructureDefinition/extension-measureScoring` |
| First measure | **CMS165v14** (Controlling High Blood Pressure) |

## Checklist (Summary MeasureReport)

Minimum fields we treat as required for Connectathon dry-runs:

- [x] `resourceType` = `MeasureReport`
- [x] `meta.profile` includes DEQM Summary StructureDefinition
- [x] `status` = `complete`
- [x] `type` = `summary`
- [x] `measure` canonical (placeholder OK until FHIR Measure package pinned)
- [x] `reporter` → Organization
- [x] `period.start` / `period.end`
- [x] `extension[measureScoring]` = `proportion` (for CMS165)
- [x] `improvementNotation` present for proportion scoring
- [x] `group[0].population[]` with IPP, DENOM, NUMER, DENEX counts
- [x] `group[0].measureScore.value` = NUMER/DENOM (or 0 if DENOM=0)
- [ ] Stratifiers (deferred until CQL evidence supports them)
- [ ] Profile validation via FHIR Validator + DEQM package (Phase 2)
- [ ] `POST` accepted by `deqm-test-server` / Connectathon receiver (Phase 2/3)

## How to regenerate

```bash
cd ~/work/vista-stack/HL7-FHIR-quality-testing
python3 scripts/build-deqm-summary.py --cms CMS165v14 \
  --ipp 14 --denom 14 --numer 14 --denex 0 --cohort-size 18 \
  --mode official-cql --source "RECOVER_CMS165_122_REPORT_LATEST.md selected-18"
python3 scripts/check-deqm-summary.py \
  docs/deqm-summary/prototypes/CMS165v14-summary-deqm.json
```

Optional receiver smoke (Phase 2):

```bash
./scripts/deqm-summary-receiver-smoke.sh
```
