### 2. Builder fixes discovered during the run

| Issue | Fix |
|-------|-----|
| VSAC XML uses `<ns0:Concept …/>`; parser only matched bare `<Concept` → 0 concepts | Parse optional namespace prefix; fail if HTTP 200 but 0 concepts |
| ELM ids are `urn:oid:…` but package used bare OIDs → `Unable to resolve expected valueset` | Emit `oid` / `_id` as `urn:oid:…`; use empty `version` |
| `Calculator.calculate` is async; evaluator did not `await` → wrote `{}` then crashed | Make `evaluate-cms165-qdm.js` `async` and `await` calculate |
